# Практикум по алгоритмам и структурам данных

## Описание проекта
Проект содержит 16 практических заданий по алгоритмам и структурам данных, разделенных на 4 тематических раздела. Каждое задание реализует ключевые концепции и структуры данных на Python.

## Структура проекта
UP_02_Algorithms_Practice/
├──README.md
├──main.py
├──requirements.txt
├──arrays_linked_lists.py
├──stack_queue.py
├──hashmap_trie.py
├──trees_graphs.py
└──heap_priority_queue.py

## Содержание заданий

### РАЗДЕЛ 1: МАССИВЫ И СВЯЗНЫЕ СПИСКИ
1. **Динамический массив** - Реализация массива с автоматическим расширением
2. **Односвязный список** - Базовые операции: вставка, удаление, поиск
3. **Двусвязный список** - Реализация с указателями на предыдущий и следующий элементы
4. **Циклический буфер** - Кольцевой буфер фиксированного размера

### РАЗДЕЛ 2: СТЕК И ОЧЕРЕДЬ
5. **Стек (LIFO)** - Реализация стека на основе массива
6. **Очередь (FIFO)** - Реализация очереди с использованием двух стеков
7. **Очередь с приоритетом** - Базовая реализация
8. **Дек (Deque)** - Двусторонняя очередь

### РАЗДЕЛ 3: HASHMAP, TRIE И ХЭШ-ФУНКЦИИ
9. **Хэш-таблица** - Реализация с разрешением коллизий методом цепочек
10. **Префиксное дерево (Trie)** - Структура для эффективного хранения строк
11. **Расширенное Trie** - Поддержка удаления и поиска по префиксу
12. **Кастомная хэш-функция** - Реализация собственной хэш-функции

### РАЗДЕЛ 4: ДЕРЕВЬЯ И ГРАФЫ
13. **Бинарное дерево поиска** - Вставка, удаление, поиск, обходы
14. **Сбалансированное дерево (AVL)** - Самобалансирующееся дерево
15. **Граф (матрица смежности)** - Алгоритмы BFS и DFS
16. **Алгоритм Дейкстры** - Поиск кратчайшего пути в графе

## Требования
- Python 3.8 или выше
- Установленные зависимости из `requirements.txt`

## Установка и запуск

1. **Клонирование репозитория:**
bash
git clone <URL-репозитория>
cd UP_02_Algorithms_Practice

1. Установка зависимостей:
bash
pip install -r requirements.txt

1. Запуск всех заданий:
bash
python main.py

1. Запуск конкретного раздела:
bash
# Пример для первого раздела
python arrays_linked_lists.py
